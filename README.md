# First-Java-CRUD

Java CRUD application for university coursework.

## Main features

- Create new car records.
- View and sort the car list.
- Update existing records.
- Delete records that are no longer needed.

## Run locally

Requirements: Java 17 or newer.

On macOS or Linux:

```bash
./mvnw spring-boot:run
```

On Windows:

```powershell
mvnw.cmd spring-boot:run
```

After startup, open [http://localhost:8080](http://localhost:8080) in a browser.
